# Support

Thanks for using **Hawkeye Sterling CDD**. This page explains where to get help
and how to get a useful answer quickly.

## Before you ask

- Read the [`README.md`](README.md) — setup, screens, scripts, and how the app
  maps to the design handoff.
- Check [`docs/COMPLIANCE-NOTES.md`](docs/COMPLIANCE-NOTES.md) and
  [`docs/GOVERNANCE-CONTROLS.md`](docs/GOVERNANCE-CONTROLS.md) for policy,
  configuration, and control questions.
- Search [existing issues](https://github.com/trex0092/hawkeye-sterling-cdd/issues?q=is%3Aissue)
  (open **and** closed) — your question may already be answered.

## How to get help

| I want to…                                | Use                                                                                                          |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Report a reproducible bug                 | [Open a bug report](https://github.com/trex0092/hawkeye-sterling-cdd/issues/new?template=bug_report.yml)     |
| Request a feature or enhancement          | [Open a feature request](https://github.com/trex0092/hawkeye-sterling-cdd/issues/new?template=feature_request.yml) |
| Ask a question or discuss an idea         | Open a [Discussion](https://github.com/trex0092/hawkeye-sterling-cdd/discussions) if enabled, otherwise a feature-request issue |
| Report a **security** vulnerability       | **Do not** open a public issue — see [`SECURITY.md`](SECURITY.md)                                             |

When filing an issue, please **never include real customer, counterparty, or PII
data** — this is an AML/CFT compliance tool and reports must stay free of live
subject data. Use redacted or synthetic examples.

## Response expectations

This is a proprietary project maintained on a best-effort basis by the repository
owner. There is no contractual SLA for community requests. Security reports are
prioritised — see the acknowledgement window in [`SECURITY.md`](SECURITY.md).

## Commercial / operational support

For deployment, licensing, or firm-policy questions (jurisdiction risk map,
retention periods, regulatory references), contact the repository owner directly.
